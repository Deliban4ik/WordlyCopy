
## 1. Назначение

Программа реализует консольную игру Wordle для русского языка. Отличительная особенность — загаданное слово передаётся в зашифрованном виде. Шифрование выполняется сдвигом каждой буквы на длину слова по порядковому номеру в алфавите.

Состав:
- `Wordle.exe` — исполняемый файл игры.
- `encode_tool.exe` — утилита для шифрования слов.
- Исходные коды (опционально).

## 2. Системные требования

- Операционная система Windows.
- Консоль с поддержкой кодировки UTF-8 (рекомендуется шрифт Consolas или Lucida Console).
- Для сборки из исходных кодов — компилятор с поддержкой C++11 (например, MinGW, MSVC).

## 3. Установка

Готовые исполняемые файлы не требуют установки. Достаточно поместить `Wordle.exe` и `encode_tool.exe` в любую директорию.

Для сборки из исходных кодов выполните команды:

```bash
g++ -c wordle_api.cpp -o wordle_api.o
g++ Wordle.cpp wordle_api.o -o Wordle.exe
g++ encode_tool.cpp wordle_api.o -o encode_tool.exe
```

## 4. Использование утилиты шифрования `encode_tool.exe`

### 4.1 Запуск с параметром командной строки

```cmd
encode_tool.exe СЛОВО
```

Пример:

```cmd
encode_tool.exe привет
```

Вывод:

```
Зашифровано: рсуёз
```

### 4.2 Запуск без параметров

При запуске без аргументов программа запрашивает ввод слова с клавиатуры:

```
Введи слово для шифрования: привет
Зашифровано: рсуёз
```

## 5. Использование игры `Wordle.exe`

### 5.1 Запуск с параметром

```cmd
Wordle.exe ЗАШИФРОВАННОЕ_СЛОВО
```

Пример:

```cmd
Wordle.exe рсуёз
```

### 5.2 Запуск без параметров

Программа запрашивает зашифрованное слово:

```
Введи зашифрованное слово: рсуёз
```

### 5.3 Ход игры

1. Отображается длина загаданного слова и количество попыток (6).
2. Игрок вводит русское слово той же длины.
3. После каждой попытки выводится подсказка:
   - `[=]` — буква находится на правильной позиции.
   - `[~]` — буква присутствует в слове, но на другой позиции.
   - `[_]` — буква отсутствует в загаданном слове.
4. Игра завершается при угадывании слова или исчерпании попыток.
5. В случае проигрыша отображается исходное (расшифрованное) слово.

### 5.4 Пример игровой сессии

```
=== Угадайка ===
Угадай слово из 6 букв. Попыток: 6
Подсказки: [=] на месте, [~] есть в слове, [_] нет в слове

Попытка 1/6: превед
[~][_][_][=][_][_]  превед

Попытка 2/6: привет
[=][=][=][=][=][=]  привет

Слово угадано за 2 попыток.
```

## 6. Примечания

- Ввод должен осуществляться русскими буквами. Использование латиницы приводит к некорректному определению длины слова.
- Буква «ё» поддерживается наравне с остальными буквами алфавита.
- Максимальная длина вводимого слова ограничена буфером 128 байт (до 64 русских символов).
- При ручной компиляции необходимо убедиться, что исходные файлы сохранены в кодировке UTF-8.
